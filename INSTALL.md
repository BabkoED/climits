# Как поставить climits

Приложение показывает лимиты Claude в строке меню macOS: сколько израсходовано
в текущем пятичасовом окне, сколько за неделю, сколько по каждой модели
и сколько потрачено сверх лимита. Те же цифры, что показывает `/usage` внутри
Claude Code - только видны всегда, даже когда Claude Code закрыт.

Нужна macOS 13 или новее. Apple Silicon и Intel одинаково.

---

## Установка, три шага

**1. Скачать.** Открыть [страницу релизов](https://github.com/BabkoED/climits/releases),
взять `climits.zip` из самого верхнего. Распаковать двойным кликом.

**2. Перетащить** `climits.app` в папку «Программы».

**3. Первый запуск - правым кликом.** Не двойным. Правый клик по значку
приложения → «Открыть» → в окне ещё раз «Открыть».

Третий шаг нужен ровно один раз. Дальше приложение открывается как обычно
и запускается само при входе в систему, если включить это в настройках.

### Почему правый клик

macOS скажет, что разработчик не подтверждён. Это не про вирусы: приложение
не подписано сертификатом Apple, потому что сертификат платный и выдаётся
на конкретного человека. Правый клик - штатный способ сказать системе,
что вы понимаете, откуда файл.

Кому привычнее одной командой в терминале:

```bash
xattr -dr com.apple.quarantine /Applications/climits.app
```

---

## Что дальше

Значок появится справа в строке меню, рядом с часами. Клик по нему открывает
список всех лимитов: шкала, процент, время до сброса. Значком `▸` отмечен тот,
который упрётся первым.

**Настройки** - в том же меню. Там выбирается, что показывать прямо в строке:
процент, время до сброса, недельный кап, модели, деньги. Кому нужен точный
формат - есть поле со своим шаблоном и живым предпросмотром.

**Автозапуск** включается там же, одной галочкой.

## Первый вопрос, который возникает у всех

**«Цифры не показываются, пишет про токен»**

Приложение читает токен, который Claude Code сам положил в связку ключей при
входе. Если Claude Code на этой машине ни разу не запускали - токена нет.
Запустите `claude` в терминале, войдите, и значок оживёт в течение пяти минут.

При первом запросе macOS спросит разрешение на доступ к связке ключей.
Нажмите «Всегда разрешать» - иначе будет спрашивать каждый раз.

**«Показывает старые цифры»**

Так и задумано. Эндпоинт Anthropic жёстко ограничивает частоту запросов,
и если очередное обновление не прошло, приложение показывает последние
известные цифры с пометкой `~` и временем, а не пустой значок. Само
восстановится.

**«Хочу разобраться, что не так»**

В приложении есть терминальный режим с диагностикой:

```bash
/Applications/climits.app/Contents/MacOS/climits --doctor
```

Он покажет, сколько записей Claude Code лежит в связке ключей, какая из них
живая, когда истекает токен, проходит ли запрос к API и какие лимиты вообще
есть в ответе. Токен при этом не печатается никогда.

Та же команда умеет `--short` - одна строка для statusline, если кому-то
нужно встроить лимиты в свою строку состояния.

Чтобы не писать длинный путь каждый раз:

```bash
/Applications/climits.app/Contents/MacOS/climits --install-cli
```

## Что приложение делает с данными

Ходит в `api.anthropic.com/api/oauth/usage` - тот же адрес, который использует
сам Claude Code для команды `/usage`. Токен берёт из связки ключей, держит
в памяти, никуда не отправляет и на диск не пишет. На диск ложится только
последний ответ сервера - чтобы было что показать, когда сети нет.

Исходники открыты, проверить можно целиком: [github.com/BabkoED/climits](https://github.com/BabkoED/climits)
